# Retrieval Gap Campaign V1 — spec

Prior campaign established evidence-*delivery* is saturated. This measures the
*retrieval* gap: on hard questions where deterministic retrieval doesn't already
surface evidence, which missing mechanism dominates — vocabulary, cross-artifact
joins, query reachability, or genuinely semantic reasoning?

Method: 40 hard questions (8 lex / 8 impl / 8 test / 8 config / 8 cross),
baseline retrieval -> sufficiency -> per-miss failure taxonomy -> conditional
experiments.
